Connection tips (CORS / local models)

Open this file locally in your browser. For a local Ollama allow the page origin: run the server with OLLAMA_ORIGINS=* ollama serve. LM Studio, llama.cpp --server, and vLLM expose an OpenAI /v1 API and usually allow CORS. For a remote Colab endpoint, use its public https URL. "Fetch models" tries /v1/models then /api/tags. Prompt "Fetch" pulls raw text from GitHub (works) — most other sites block cross-origin fetch.
